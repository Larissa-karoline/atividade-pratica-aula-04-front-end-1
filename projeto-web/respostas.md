#Respostas das atividades

##Atividade 1
Qual será a funcao do arquivo index.html e qual sera a funcao do arquivo style.css
**Resposta:** 
index.html define a estrutura e o conteudo da pagina 
style.css define o estilo visual, as cores e aparencia da pagina

##Atividade 2
Qual declaração deve aparecer no inicio do documento para indicar que ele utiliza HTML5?
**Resposta:**
a declaraçao <!DOCTYPE html>

##Atividade 3
qual tag HTML deve ser utilizada para definir esse tıtulo?
**Resposta:**
a tag <title></title>

##Atividade 4 
Qual tag representa o tıtulo principal e qual tag representa um paragrafo?
**Resposta:**
a tag <h1> apresenta o titulo principal
a tag <p> representa o parágrafo

##Atividade 5 
qual elemento HTML5 deve ser utilizado para representar uma secao tematica de conteudo?
**Resposta:**
a tag <selection>

##Atividade 6
qual elemento HTML5 deve ser utilizado para agrupar links de navegacao?
qual atributo da tag <a> define o destino do link?
**Resposta:**
a tag <nav> agrupa links de navegaçao
o atributo href define o destino do link

##Atividade 7

secao chamada sobre?
**Resposta:**
deverá utilizar o atributo id.
